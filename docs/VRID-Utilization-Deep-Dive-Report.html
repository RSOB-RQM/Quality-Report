7. Execution Framework — Ongoing Mechanism

Step 1: Weekly Site Identification (5 min)

  • Pull site utilization for all sites with 10+ active loads
  • Flag sites below 60% utilization
  • Identify sites trending downward (Wk-over-Wk decline > 5pp)

Step 2: Site-Level Deep Dive (15 min per site)

  • Analyze platform split (CASA vs FMC) for each flagged site
  • Identify dominant adhoc bucket driving low utilization
  • Determine if issue is CASA-driven (premature creation) or FMC-driven (system logic)
  • Classify root cause using framework above

Step 3: Site Outreach & Follow-Up

  • Share site-specific findings with POC (platform split, bucket breakdown, trend)
  • Request observations: What is causing low fill at their site?
  • Set up bi-weekly 15-min sync with top priority sites
  • POCs to suggest process/timing changes that could improve fill rates

10. Key Recommendations

1. Address CASA Load Creation Logic (Primary Lever)
CASA loads run at 29.8% — half the rate of FMC. Implementing a minimum fill threshold before CASA allows load dispatch could move overall utilization from 51.4% toward 57-60%.

2. Prioritize "FC Underutilized" Bucket
This bucket runs at 18.8% utilization across 2,421 loads. Loads are being created with almost no freight available — single biggest opportunity.

3. Site-Specific Engagement for Tier 1 Sites
Top 10 underutilized high-volume sites need direct POC engagement to understand local factors.

4. Build Repeatable Mechanism
Weekly/bi-weekly/monthly cadence ensures sustained improvement and provides leadership with ongoing visibility.
