### Background

One of the gaps we identified in our current quality governance is the **timeliness and consistency of quality performance communication** to associates. Today, quality data reaches associates primarily through manager-driven channels — weekly emails, 1:1 discussions, and ad-hoc data pulls. This approach introduces:

- **Delays** in associates receiving feedback on their audit outcomes
- **Inconsistency** in the depth and format of information shared across teams
- **Dependency** on managers for associates to access their own performance data
- **Effort duplication** as managers manually compile and distribute updates each week

To address this, we have developed a centralized, role-based dashboard that provides associates, managers, and leadership with direct access to quality performance data — without requiring any manual intervention.

---

### Solution Overview

The **RSOB Quality Performance Dashboard** is a browser-based tool that provides instant, self-service access to RQM audit data. It is updated weekly and requires no software installation.

🔗 **Dashboard URL:** https://RSOB-RQM.github.io/Quality-Report/

---

### Dashboard Walkthrough

Upon login, users will navigate through the following tabs:

| Tab | What It Shows |
|-----|---------------|
| **Glossary** | Reference guide explaining all 5 quality attributes (ADM, RA, RRC, ACC, RV), scoring methodology, and improvement actions taken |
| **Dashboard** | Role-specific performance view — defect rates, error breakdown, week-wise trends, common findings, and best practices |
| **Raw Data** | Transaction-level audit records with search and filter capabilities |
| **Leadership Report** *(Admin only)* | Process-wide analysis including region comparison, manager performance, shift-wise data, and appeal summary |

Each tab is designed to provide relevant information at the right level of detail based on the user's role.

---

### Role-Based Access

| Role | What They Can Access |
|------|---------------------|
| **Associate** | Personal performance — defect rate, error details, trends, and best practices |
| **Manager** | Team summary — associate-wise comparison, defect types, repeated defaulters |
| **Leadership / Admin** | Full process view — region-wise, manager-wise, shift-wise analysis |

Access is controlled through individual login credentials. Each user sees only the data relevant to their role.

---

### Key Capabilities

- **No installation required** — works in any browser (Chrome/Edge recommended)
- **Role-based security** — associates see only their data; managers see their team
- **Weekly updates** — data refreshed every week with latest RQM audit results
- **CSV export** — all tables can be downloaded for offline use
- **Quality Glossary** — built-in reference for audit parameters and scoring
- **Actions & Impact** — documents interventions and their measurable outcomes
